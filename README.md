\# ⚡ CrisisIQ — AI-Powered Financial Intelligence Platform



A professional financial stress testing and decision intelligence platform for Indian companies.



\## Features

\- 📊 Live financial data for 500 Nifty companies

\- ⚡ Crisis Simulator with stress testing

\- 🧪 Resilience Lab with intervention analysis

\- 🤖 AI Boardroom with 6 specialized agents

\- 🔄 Counterfactual Strategy Analysis

\- 🏢 Company Comparison

\- 🔮 ML Stock Price Prediction with news sentiment

\- 📐 Industry Benchmarks and Advanced Ratios

\- 📄 PDF Report Export



\## Tech Stack

\- Python + Streamlit

\- Yahoo Finance (yfinance)

\- Plotly charts

\- Scikit-learn ML

\- Anthropic Claude AI

\- ReportLab PDF



\## How to Run



\### 1. Clone the repository

git clone https://github.com/yourusername/crisisiq.git

cd crisisiq



\### 2. Install dependencies

pip install -r requirements.txt



\### 3. Set API key (optional - only for AI Boardroom)

set ANTHROPIC\_API\_KEY=your-api-key-here



\### 4. Run the app

streamlit run app\_new.py



\### 5. Open browser

Go to http://localhost:8501
